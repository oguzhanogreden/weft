## Notes

- **Router service bug (P8):** an app-wide Effect service (`Context.Tag`) is **not**
  reachable from route components — neither ambient `Effect.provide(render, L)` nor
  `provideService` on the outlet node works, because the reactive outlet's leaf stream
  drains in `renderToStringHydratable`'s top context. Filed as
  `packages/router/ambient-context-propagation.specs.md`. Workaround: doc model is a
  **module singleton** `liveDocs` imported directly by components. Test seam without
  mocking: the `weftDocs` plugin is registered in the **root** `vite.config.ts` so
  `virtual:weft-docs` resolves under `vp test` to the real baked docs.
- **Pre-existing toolchain gap:** `vp test` cannot resolve the `~/*` tsconfig path
  alias (vitest 4.1.9 / vite-plus 0.2.x), so `packages/*` tests that import `~/index`
  fail to load (27 files) — even run from their own package dir. Repo-wide, predates
  this work, unrelated to the website (website tests use relative + `@weftui/*` imports
  and all pass). The 0.2.x migration needs a tsconfig-paths fix. Revisit at P10 before
  claiming `vp run test` green.
- **Toolchain (P1):** catalog `vitest: 4.1.9` (real vitest that vite-plus 0.2.1 depends on), global `vp` upgraded to 0.2.1. `vp test`/`vp check` green. Run node tests with `vp test <name>`.
- **Testing the virtual module:** node tests can't resolve `virtual:weft-docs` (root vitest has no website plugin). Mock with `vi.mock("virtual:weft-docs", () => ({ getAllDocs: () => [] }))` and unit-test the pure builder directly (see `nav.test.ts`).
- `render-hast` (P6) consumes hast-style camelCase props: `className` array → `class`; code `<pre>` carries `dataLang`/`dataRaw`/`dataDemo`; `dataDemo` present → render `Demo` instead of `CodeBlock`. `CodeBlock` receives already-rendered `tokens: Renderable[]` (renderHast renders the `<code>` children then hands them in — no import cycle).
- Doc model facts: api section = core/dom/router (order 1/2/3); `firstDocPath` → `/docs/guides/getting-started`; `docs/index.md` excluded (no frontmatter).
- **Before writing P3/P5/P9 components:** study Weft component API — read `docs/concepts/combinator-api.md`, `docs/concepts/reactive-primitives.md`, and an example app (`examples/declarative-event-handlers`, `examples/subscription-ref`) for `h`, reactive handlers, `SubscriptionRef`, stream-as-children, SSR/hydrate-inert patterns. No JSX.
